# 문서 양식

새 글에는 **[작성양식/](작성양식/README.md)**의 네 가지 양식을 사용하세요. 메타데이터·정답 접기·이미지/PCAP·GitHub 게시 순서까지 안내합니다.

| 위치                                                | 용도                                                            |
| --------------------------------------------------- | --------------------------------------------------------------- |
| [작성양식/](작성양식/README.md)                     | 현재 권장 양식: 개념·실험·연구·문제                             |
| `concept.md`, `lab.md`, `research.md`, `problem.md` | 초기 영문 기본형. 기존 글의 참조 경로를 유지하기 위한 호환 자료 |
| [archive/](archive/README.md)                       | 개선 전 비교 자료와 원본 보관                                   |

양식 폴더는 사이트의 문서 컬렉션에 포함되지 않습니다. 게시하려면 양식을 `src/content/docs/`의 해당 위치에 복사하세요.

## 개선본 채택 이유

- 개념: 적용 범위·성립 조건·예외와 설명용 예시를 구분합니다.
- 실험: 미수행 상태와 관찰을 구분하고 환경·통제 변수·재현 조건을 기록합니다.
- 연구: 경쟁 가설과 근거·반례를 비교하고 사실과 판단을 나눕니다.
- 문제: 풀이 시도·오답 원인·검산법과 출처를 안내합니다.

기본 양식에는 MDX의 `url as assetUrl` 수정과 중복 HTML 주석 제거까지 반영했습니다. 비교용 원본은 archive에 보존했으며, 새 글에는 기본 양식을 사용합니다.
